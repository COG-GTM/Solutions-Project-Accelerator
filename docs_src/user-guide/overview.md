## Workflows

- **Import a project** — bring P&IDs, control philosophies, and equipment lists
  into a project.
- **Extract HMI graphics** — turn P&ID symbols into HMI graphic templates.
- **Pair graphics with control modules** — link extracted graphics to ACM
  objects.
- **Build displays** — lay out HMI displays automatically from paired graphics.
- **Build the PLC** — generate ACM project artefacts.
- **Build the HMI** — generate the HMI project artefacts.

Detailed pages for each workflow will land here as the migration completes.
