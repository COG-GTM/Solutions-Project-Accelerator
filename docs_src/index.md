# Solutions Project Accelerator

Solutions Project Accelerator is a desktop application that uses AI to extract
design information from piping and instrumentation diagrams (P&IDs), control
philosophies, and equipment lists, and to help build the corresponding
PLC / HMI artefacts in Rockwell Automation tooling.

!!! info "Offline documentation"
    You are viewing this documentation from your local copy of the
    application. It needs no internet connection.

## What you can do with the app

- **Extract static graphics templates** from P&IDs, keeping a reference back to
  the source document to help visual style alignment across HMIs.
- **Position process objects and static graphics** onto HMI displays based on
  their positions on the P&IDs and a user-defined area.
- **Extract pipeline connections** between equipment and plot them onto HMI
  displays.
- **Extract code from Control Philosophies** by looking at similarities between
  interlock or sequence text, keeping a reference back to the source documents.
