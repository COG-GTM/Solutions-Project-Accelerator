# Introduction


> This Solutions Project Accelerator (SPA) Training Manual explains how to use SPA to convert project information into control modules, static graphics, and dynamic HMI graphics.

## Intent

This manual gives engineers the working knowledge needed to use SPA on future projects. It will be revised as SPA gains new functions, and readers can complete the training at their own pace.

## Scope

This manual is divided into modules that explain SPA’s main workflows.

The modules cover the following topics:

- Prerequisites

- How to Create a Project

- How to Scan Control Modules

- How to Extract Static Graphics

- How to Scan HMI Display Pages and Page Links

- How to Import and Export Project Data

- How to Build HMI Display Pages

- How to Link Object Parameters

- How to Link Subobject Parameters
